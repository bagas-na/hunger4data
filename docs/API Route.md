## User
- POST /user/register: Endpoint buat registrasi
- POST /user/login: Endpoint buat login
- GET /user/{id}: Get user dengan id
- PUT /user/{id}: Update data user
- DELETE /user/{id}: Update data user

## Payment
- POST /payment/create: Endpoint untuk membuat transaki
- GET /payment/: Endpoint untuk mengambil data dari payment
- PUT /payment/{id}: Update data payment
- DELETE /payment/{id}: Update data payment

## Subscription
- POST /subscription/subscribe: Endpoint Membuat subsciption
- GET /subscription/: Get subscription
- PUT /subscription/{id}: Update data subscription
- DELETE /subscription/{id}: Update data subscription

## Nation
- POST /nation/: Endpoint Membuat nation
- GET /nation/: Get negara
- PUT /nation/{id}: Update data nation
- DELETE /nation/{id}: Update data nation

## Notification
- POST /notification/send: Endpoint untuk mengirim email notifikasi
